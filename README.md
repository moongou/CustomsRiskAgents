# CustomsRiskAgents

风控全流程多智能体协同平台的静态展示页，集中介绍 14 个应用及共享 AI 组件。页面不需要构建步骤或运行时依赖。

## 本地预览

```bash
APP_PORT=6519 bash scripts/dev-dashboard-start.sh
```

然后打开 <http://127.0.0.1:6519/>。按 `Ctrl+C` 停止服务。

页面内容位于 `index.html`，样式位于 `styles.css`，交互位于 `script.js`；原创 SVG 和本地字体分别位于 `assets/` 与 `fonts/`。

## 应用状态

页面中的插画是概念视觉。全球中标合同平台仍在建设及本机试运行；战法平台展示研究草案与合成验证；关键矿产平台包含研究原型与内置成果展示。
